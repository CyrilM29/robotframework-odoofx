robotframework-odoofx: keyword documentation

OdooFxLibrary brings Odoo test automation to Robot Framework through two channels under one keyword vocabulary: the web client, driven through the Browser library, and the external API (XML-RPC up to Odoo 18, JSON-2 from Odoo 19), with ORM introspection and opt-in, journaled writes, an HTTP channel and the report PDFs Odoo prints.

Alpha. Both channels work and are proven live on Odoo 16 and Odoo 19 Community. Writes are off unless the connection or the web login opts in, and every write is journaled. Not covered yet: the kanban, calendar, pivot and graph views, the chatter, the mass actions of a list, Odoo's legacy /jsonrpc route. Create New Quotation is a skeleton that only warns.

Keyword reference

OdooFxLibrary

Web client and RPC channels

Prove the target, log in and navigate by external id, search a list, enter and save forms, work in wizards, count and read records, compare state codes, introspect the ORM, write with a journal, call Odoo over HTTP, read and assert the report PDFs.
