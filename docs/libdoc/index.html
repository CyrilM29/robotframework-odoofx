robotframework-odoofx: keyword documentation

OdooFxLibrary brings Odoo test automation to Robot Framework: the RPC channels (XML-RPC up to Odoo 18, JSON-2 from Odoo 19), ORM reads and opt-in, journaled writes, under one keyword vocabulary.

Bootstrap phase. The RPC channel works, reads and writes (writes are off unless the connection opts in). The web channel is a skeleton whose keywords only warn: a suite that calls them proves nothing about them.

Keyword reference

OdooFxLibrary

RPC channel, ORM reads and writes

Connect and prove the target, count and read records, compare state codes, write with a journal and a way back.
